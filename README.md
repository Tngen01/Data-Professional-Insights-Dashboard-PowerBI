# Data-Professional-Insights-Dashboard-PowerBI

## Overview

This project presents an interactive Power BI dashboard that analyzes survey responses from data professionals across different countries and job roles. The dashboard provides insights into salary trends, work-life balance, career satisfaction, preferred programming languages, and the challenges faced when entering the data industry.

The project was completed as part of my Power BI learning journey by recreating and understanding a guided dashboard project. Through this project, I gained hands-on experience in data cleaning, data transformation, data modeling, visualization design, and dashboard development using Power BI.

---

## Project Objectives

* Analyze survey responses from data professionals.
* Compare average salaries across different job roles.
* Identify the most popular programming languages.
* Understand work-life balance satisfaction among professionals.
* Explore the difficulty of breaking into the data field.
* Visualize demographic information such as age and country distribution.

## Dashboard Features

### Country Distribution

Displays the geographical distribution of survey respondents.

### Average Salary by Job Title

Compares average salaries across various data-related roles including:

* Data Scientist
* Data Engineer
* Data Architect
* Data Analyst
* Database Developer

### Favorite Programming Languages

Shows the most preferred programming languages among survey participants.

### Difficulty to Break Into Data

Analyzes respondents' opinions on how difficult it is to enter the data industry.

### Work-Life Balance Analysis

Measures overall work-life balance satisfaction among survey respondents.

### Demographic Insights

Provides information such as:

* Total Survey Participants
* Average Age of Participants

---

## Key Insights

* Python is the most preferred programming language among data professionals.
* Data Scientists report the highest average salaries.
* Work-life balance satisfaction is relatively positive among respondents.
* Many participants consider entering the data field moderately difficult.
* Survey responses were collected from multiple countries, with significant participation from the United States, India, Canada, and the United Kingdom.
